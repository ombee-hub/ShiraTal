# שירה טל — אתר תדמית

עיצוב ובנייה מחדש של האתר של **שירה טל** — מרצה מעוררת השראה ומאמנת אישית.

## מבנה
אתר סטטי (HTML/CSS/JS) ב-8 דפים נפרדים, עברית RTL, רספונסיבי:

| דף | קובץ |
|----|------|
| בית | `index.html` |
| עליי | `about.html` |
| על ההרצאה | `lecture.html` |
| אימון אישי | `coaching.html` |
| הישגים | `achievements.html` |
| גלריה | `gallery.html` |
| המלצות | `testimonials.html` |
| יצירת קשר | `contact.html` |

- `style.css` — עיצוב משותף לכל הדפים
- `script.js` — תפריט מובייל, אנימציות גלילה, טופס
- `images/` — תמונות

## הרצה
פתיחת `index.html` בדפדפן (אין תלות בשרת).
